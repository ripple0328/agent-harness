## Source Guardrails

- DesEngs inclusion is a useful curation signal, not independent validation.
- Check the linked resource, license, maintenance status, accessibility, and
  project fit before adopting code or advice.
- Prefer principles that recur across independent sources over one fashionable
  aesthetic.
- Record broken links and significant taxonomy changes in a dated research note.
