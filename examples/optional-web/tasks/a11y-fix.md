# Task: a11y-fix

## Use When

Accessibility issues have been found and the user wants them fixed.

## Load

- `examples/optional-web/tasks/a11y-check.md`
- `examples/optional-web/rules/web-ui.md`
- relevant UI code and tests

## Steps

1. Read each accessibility finding.
2. Apply the smallest semantic fix.
3. Add or update tests for behavior that can regress.
4. Re-run the relevant accessibility checks.
5. Report remaining gaps.

## Output

- code changes
- tests updated
- verification evidence
- unresolved accessibility risks
