# Optional web interface extension

Historical web and visual guidance lives here to keep the default harness
independent of product type. Nothing here is loaded by the core rules. Adopt
only for a project with a relevant interface, its approved design system and
actual tool capabilities. Provider-specific CI examples similarly remain in
`examples/ci/`; they are adapters, not portable requirements.

The original design research remains under `docs/design/` as reference material.
Validate links and local paths when copying this extension into another project.
