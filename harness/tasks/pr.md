# Task: pr

## Use When

The user wants to prepare a pull request or equivalent change request.

## Load

- `harness/workflows/pr.md`
- `harness/templates/pr-attention-packet.md`
- linked spec and QA report
- project-local PR conventions

## Steps

Follow `harness/workflows/pr.md`.

## Output

- PR title
- PR body with PR Attention Packet
- validation plan
- not-verified items
- harness feedback link if any
