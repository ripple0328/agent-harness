# Task: define-epic

## Use When

The user wants to group related features under a larger outcome.

## Load

- `harness/templates/epic.md`
- `docs/spec-driven-process.md`
- existing `specs/epics/` or equivalent project directory

## Steps

1. Clarify the outcome, users, and success measures.
2. Identify existing or planned feature specs that belong to the epic.
3. Capture dependencies and out-of-scope areas.
4. Save the epic from `harness/templates/epic.md`.
5. Report linked features and open gaps.

## Output

- epic spec path
- feature list
- success measures
- open questions
